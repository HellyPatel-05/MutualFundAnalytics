# Bluestock MF Analytics — Capstone Project

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue)](https://python.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-v1.0-orange)](https://github.com)

An end-to-end Indian mutual fund analytics platform covering **40 equity, debt, and hybrid fund schemes**. It ingests live NAV data from the AMFI API, cleans and stores it in a SQLite star-schema database, runs quantitative performance analytics, and surfaces results through a 4-page Power BI dashboard and a CLI fund recommender.

## Project Overview

| Item | Detail |
|------|--------|
| **Domain** | Indian Mutual Funds (SEBI-regulated) |
| **Scope** | 40 fund schemes across Large Cap, Mid Cap, Small Cap, Debt, Hybrid |
| **Date Range** | January 2022 – December 2025 |
| **Data Source** | [mfapi.in](https://api.mfapi.in) (free public AMFI NAV API) + synthetic institutional datasets |

| **Dashboard** | Power BI Desktop (4 pages, 8 tables, 25+ visuals) |
| **Analytics** | CAGR, Sharpe, Sortino, Alpha/Beta, VaR/CVaR, Max Drawdown, Fund Scorecard |

### Objectives Met

1. ✅ Data ingestion from live AMFI API and 10 structured CSVs
2. ✅ ETL pipeline with cleaning, validation, and SQLite loading
3. ✅ Exploratory Data Analysis — 15 publication-quality charts
4. ✅ Performance analytics — CAGR, Sharpe, Sortino, Alpha, Beta, drawdown
5. ✅ Advanced analytics — VaR/CVaR, rolling Sharpe, SIP continuity, HHI
6. ✅ Fund Scorecard (composite 0–100 ranking) and CLI recommender
7. ✅ Power BI dashboard — 4 interactive pages
8. ✅ Final report and 12-slide presentation

## How to Run the ETL Pipeline

### Option A — Run Everything at Once (Recommended)

```bash
python scripts/etl_pipeline.py
```

This master script runs all stages in sequence:
1. Fetch live NAV data from mfapi.in
2. Run EDA analysis (generates 15 charts)
3. Run performance analytics (CAGR, Sharpe, Alpha, Scorecard)
4. Run advanced analytics (VaR, cohorts, HHI, rolling Sharpe)

Expected runtime: **3–8 minutes** depending on internet speed.

### Option B — Run Each Stage Individually

```bash
# Stage 1: Fetch live NAV data
python scripts/live_nav_fetch.py

# Stage 2: EDA + charts
python run_eda.py

# Stage 3: Performance analytics
python scripts/compute_metrics.py

# Stage 4: Fund recommender (interactive)
python scripts/recommender.py --risk Moderate
```

### Output Locations

| Output | Location |
|--------|----------|
| EDA charts (15 PNG) | `reports/charts/` |
| Performance charts (4 PNG) | `reports/charts/` |
| Advanced analytics charts (5 PNG) | `reports/charts/` |

| Alpha/Beta table | `data/processed/alpha_beta.csv` |

## Fund Recommender

```bash
# Interactive mode
python recommender.py

# By risk appetite
python recommender.py --risk Low
python recommender.py --risk Moderate
python recommender.py --risk "Moderately High"
python recommender.py --risk High
python recommender.py --risk "Very High"

# Aliases
python recommender.py --risk conservative   # → Low
python recommender.py --risk balanced       # → Moderate + Moderately High
python recommender.py --risk aggressive     # → High + Very High

# Top N recommendations
python recommender.py --risk Moderate --top 5
```

The recommender ranks funds by **composite score** (30% 3yr CAGR + 25% Sharpe + 20% Alpha + 15% low TER + 10% low drawdown), filtered to the requested risk grade.

## How to Open the Dashboard

### Requirements

- **Power BI Desktop** (free) — [Download here](https://powerbi.microsoft.com/desktop)
- All processed CSVs must be present in `data/processed/`

### Steps

1. Open **Power BI Desktop**
2. Load data using the M queries in `dashboard/powerbi_m_queries.txt`
   - Go to **Home → Transform Data → New Source → Blank Query**
   - Open **Advanced Editor** and paste each query block
   - Update the file path `D:\MutualFundAnalytics\` to your local path
3. Apply the theme: **View → Themes → Browse → `dashboard/bluestock_theme.json`**
4. Add DAX measures from `dashboard/dax_measures.txt`
5. Follow the full step-by-step guide in `dashboard/PowerBI_Build_Guide.md`

### Dashboard Pages

| Page | Description |
|------|-------------|
| **Industry Overview** | KPI cards (AUM ₹81L Cr, SIP ₹31K Cr, Folios 26.12 Cr), AUM trend, AMC bar |
| **Fund Performance** | Scatter (return vs risk), NAV line chart, sortable fund scorecard with drill-through |
| **Investor Analytics** | SIP by state, age group analysis, transaction type mix, monthly volume |
| **SIP & Market Trends** | Dual-axis (SIP + Nifty 50), category inflow heatmap, FY25 top categories |

## Key Findings

1. **SIP momentum:** Monthly SIP inflows hit ₹31,002 Cr ATH in Dec 2025 (17% YoY growth). Industry folios reached 26.12 Cr — crossing 15 Cr in 2023 and 18 Cr in 2024.
2. **AUM dominance:** SBI Mutual Fund leads with ~₹12.5 Lakh Crore AUM; industry total ~₹81 Lakh Crore.
3. **High-quality funds:** Funds passing the quality screen (Alpha > 1% AND Sharpe > 1) form the core recommendation universe.
4. **2023 bull run / 2024 correction:** Rolling Sharpe ratios visibly compressed during the Sep–Dec 2024 market correction; all 5 key funds recovered in 2025.
5. **Direct plans outperform:** Direct plan expense ratios average 0.5–1.0% lower than regular plans, compounding meaningfully over 5 years.
6. **T30 city dominance:** Maharashtra and Delhi account for the highest SIP volumes; B30 cities showing accelerating adoption.
7. **SIP continuity:** ~82% of active SIP investors maintain regular cadence; ~18% are at-risk (avg gap > 35 days).
8. **Sector concentration:** Most equity funds are well-diversified (HHI < 0.15); Financial Services and IT are the top sectors across all portfolios.
